# Guide to Using Themes in ProPresenter
Themes in ProPresenter allow you to apply consistent styles—like text formatting, shapes, and media across multiple slides in your presentation.

### Accessing the Theme Editor:

There are two ways to access it:

- Click the **More** button in the toolbar and select **Theme Editor**.
- Or, click the **Theme** button in the toolbar, hit the **+** to create a new theme, or choose an existing theme and press the pen icon to edit.

### Using the Theme Editor:

Once in the **Theme Editor**, you’ll see all the familiar tools from the standard ProPresenter editor, but the focus is on styling rather than entering specific text.

#### Text Customization:

In the **Text Tab**, you can set the default styling that will apply to all text added through the theme. Here’s how:

- **Font & Size**: Select your desired font and font size.
- **All Caps**: You can choose to apply all caps to the text if needed.
- **Text Scaling**: Enable automatic text scaling to ensure that all text fits within the text box, regardless of how much content there is.
- **Advanced Text Options**: Add effects like stroke, shadow, or text linking. You can also enable scrolling text if that’s necessary for your theme.

#### Shape Customization:

- Go to the **Shape Tab** to add and style shapes. You can insert rectangles, circles, and other shapes, and adjust their properties like **fill**, **stroke**, **shadow**, and **feathering**. These shapes can be used to enhance the design of your slides.
- Just like with text, shapes can be easily resized or repositioned to fit the design.

### Adding Media:

Themes also allow you to add media actions:

- In the **Theme Tab**, you can add a **media action** (like an image or video) to the theme. This action will be applied to all slides using that theme, but it will be applied to the **media layer**, not the **slide layer**.
- If you want to add media directly to the slide layer (for instance, a background image for each slide), use the **media button at the top** of the **Theme Editor** to add media directly to the slide layer.

### Preview and Apply:

After creating or editing your theme, you can preview how it looks across your slides. This ensures that everything from text formatting to media displays correctly before applying the theme to your presentation.

### Applying Themes to Slides:

Once your theme is ready, applying it to your slides is simple. Select the slides you want to update, right click, hover on theme, and then choose your theme and watch as your text styles, media, and shape choices populate across multiple slides seamlessly.
